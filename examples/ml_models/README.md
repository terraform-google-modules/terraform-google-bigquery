# terraform-google-bigquery ml_models

This example illustrates how to create a BigQuery ML remote model on a Vertex AI embedding model using the `ml_models` module.

## Outputs

| Name | Description |
|------|-------------|
| connection\_id | Fully qualified connection id (project.location.connection\_id) |
| models | Fully qualified ids of the created models |

## Usage

Run the following commands within this directory:
- `terraform init` to get the plugins
- `terraform plan` to see the infrastructure plan
- `terraform apply` to apply the infrastructure build
- `terraform destroy` to destroy the built infrastructure
